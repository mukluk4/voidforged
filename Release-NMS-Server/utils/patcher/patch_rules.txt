# What build_manifest.py ships from the reference client folder.
# Patterns are fnmatch globs against the lowercase path relative to the client folder, with / separators.
# A directory pattern ends in /** to cover everything below it.
#
#   exclude <glob>     never shipped, and the patcher never touches it on a player's PC
#   ifmissing <glob>   shipped for fresh installs only; a player's own copy is never overwritten
#   delete <path>      removed from players' folders (for files we used to ship)
#   stray <glob>       top-folder files on a player's PC that match and aren't shipped get moved to VoidPatcher_backup/
# The first exclude or ifmissing rule that matches a path wins.

# Zone and model files from other clients. The game prefers a zone's .eqg over its .s3d, so a newer
# nektulos.eqg (not in our client) drops players under the world the server's map was built for.
stray *.eqg
stray *.s3d
stray *.zon
stray *.emt
stray *.xmi
stray *.eff
stray *_chr.txt
stray *_chr2.txt
stray *_assets.txt
stray *_environmentemitters.txt

# Player settings: give new installs a starting copy, never overwrite after that
ifmissing eqclient.ini
ifmissing defaults.ini
ifmissing eqlsuiconfig.ini
ifmissing voicechat.ini
ifmissing eqoptions1.opt
